# The Vacuum's Alibi

A one-line excuse a robot vacuum gives for missing a spot — deadpan sensor-log
voice, one surprising twist, punch at the end. `main.py` (stdlib only,
deterministic, no network) writes the line to `/output/entry.txt`, or to
`$OUTPUT_PATH` when set.

> Log 04:12: I did not miss that spot. My sensors classified the dust bunny as
> a protected species, and my warranty does not cover extinction.
